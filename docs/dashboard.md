# Workspace dashboard

The customer shell now has its collapse/expand control directly under the logo, above navigation. The desktop preference persists on the device; mobile navigation remains a full-width drawer. The back-office toggle is also at the top.

The dashboard uses actual wallet, project, distribution and last-30-day audience data. It shows the first name from a saved founder profile on the workspace's projects when one exists, otherwise the workspace name (signup currently collects a business name, not a separate personal name). No engagement figures or trend charts are invented.

The top toolbar is functional throughout the customer workspace:

- Search filters loaded workspace videos, distribution requests and page shortcuts. Results link to the matching destination; Escape or clicking outside closes the panel.
- Notifications show ready/failed/retake videos and published outlet placements. Mark-all-read is persisted by workspace on the device. This activity panel does not replace existing transactional email notifications.
- Settings links to the brand kit, account/data, security and credit/payment pages.

Panels report unavailable activity rather than treating a failed request as no activity. The new toolbar reuses existing query keys and authorization; it does not alter video creation, distribution payment or authentication flows.
